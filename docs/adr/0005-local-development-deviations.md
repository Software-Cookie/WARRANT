# ADR 0005: Local development deviations

Status: accepted

| Production | Local (`WARRANT_ENV=local`) | Why it is safe |
| --- | --- | --- |
| Cloud SQL IAM authentication | Postgres trust auth on a private Docker network with no published port | Refused outside development (`DataSourceConfig`). |
| Cloud KMS signing | Ed25519 keys generated into a Docker volume, kid prefixed `dev-` | Production verifiers reject `dev-` keys (`KeyTrustPolicy.PRODUCTION`). |
| Google sign-in | Development sessions by seeded email | Endpoint returns 404 outside development. |
| Secret Manager | `.local/secrets` files generated by `scripts/dev-bootstrap.sh` | Git-ignored; `local-secret://` refused outside development. |
| Memorystore TLS + AUTH | Redis without auth on the private network | Not published to the host. |
